## 📌 Overview

Managing technical events at colleges can quickly become complicated.

Registrations may happen through Google Forms, participant lists are maintained in spreadsheets, announcements are shared through WhatsApp, attendance is recorded manually, judges use separate methods for evaluation, and certificates often have to be prepared after everything is over.

While each of these tools works on its own, putting everything together becomes time-consuming and difficult to manage.

**Pedagogy** was built to bring all of these processes into one centralized platform.

It allows students, faculty, judges, volunteers, and administrators to work within the same system, with each role getting the tools and access they actually need.

From creating an event and registering participants to managing teams, scanning QR codes for attendance, conducting evaluations, publishing results, generating certificates, sending announcements, and viewing analytics, the complete event workflow can be managed through Pedagogy.

# 🎯 Problem Statement

Technical events are an important part of college life, but managing them often involves a lot of manual coordination.

Organizers commonly have to deal with:

- 📋 Registrations spread across different forms
- 📊 Participant data maintained in spreadsheets
- 📝 Manual attendance and participant verification
- 👥 Difficulty managing teams and team members
- ⚖️ Separate processes for judges and evaluations
- 🏆 Manual result preparation and publishing
- 📜 Time-consuming certificate generation
- 🔔 Event announcements spread across different platforms
- 📈 Limited visibility into participation and event performance
- 🔐 Different tools with no centralized access control

As the number of participants and events increases, keeping all of this synchronized becomes even harder.

Pedagogy addresses this by providing **one connected system for the entire event lifecycle**.

---

# 💡 Our Solution

Pedagogy brings the different parts of technical-event management together into a single platform.

Instead of switching between multiple tools, organizers can manage an event from one dashboard while students, judges, volunteers, and administrators get their own role-specific interfaces.
